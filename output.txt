1 Agenda
The Agenda feature in the Talentwunder app is designed to manage tasks and activities, for 
overview and organization of all candidate-related actions. Users can create tasks or actions, 
which are then categorized and displayed for easy tracking. The Agenda provides three main 
views:

Completed: A list of tasks that have been finished.

stay on top of deadlines and schedules. The feature also includes a detailed view where all task  
information is displayed. This detailed view allows users to sort tasks by due date or Project and  
filter tasks by their type (all tasks, completed, uncompleted), making it easy to focus on what's 
most important. With these capabilities, the Agenda feature simplifies activities overview and 
keeps things organized.

2 Notifications
The Notifications section in the Talentwunder app provides a way to manage and filter 
notifications. Users can view all notifications or filter them to see only unread ones. Notifications 
can also be marked as read or deleted for better organization.
A dedicated Settings button allows users to customize their notification preferences. This 
includes enabling or disabling app notifications (e.g., activity updates) and configuring email 
notifications, such as receiving daily or weekly summaries at preferred times and days. This 
setup ensures users stay updated while maintaining control over their notification flow.
2.1 All
Notifications are triggered based on the SaaS Notification Service and cover the following 
events:
2.1.1. Project Actions:
   - Create: Notification is sent when a new project is created.
   - Delete: Notification is sent when a project is deleted.
   - Close/Reactivate: Notifications are sent when a project is closed or reactivated.
2.1.2. Project Modifications:
   - Status Changes: Notifications are sent when a project's status is modified.
   - Renaming: Notification is triggered when a project is renamed.
   - Member Changes: When project members are added or removed, all previous members 
(except the one who made the changes) receive a notification.
2.1.3. Candidate Actions:
   - Add/Remove Candidates:  
     - If an unread notification for the same type of candidate action (add/remove) already exists, 
the notification will aggregate.

3.1.3.2. Two-Factor Authentication (2FA):  
To set up Two-Factor Authentication (2FA) in the Talentwunder app, follow these simple steps:
 
1. Download and Install the Authentication App:
   - Download the Google Authenticator app on your mobile device from either the Google Play 
Store (for Android devices) or the Apple App Store (for iOS devices).
2. Scan the QR Code:
   - Open the Google Authenticator app and use the QR code scanning option to scan the QR 
code displayed on the screen. This will link your account with the authenticator app.
3. Verify the Authentication Code:
   - The app will generate a unique 6-digit code that changes every few seconds.
   - Enter this code into the "Authentication Code" field in the app and click Verify Code.
Once verified, your Two-Factor Authentication is successfully enabled. This ensures that in 
addition to your password, you’ll need the unique code from the authenticator app to log in to 
your account. This adds an extra layer of security to protect your data.
The screen in the app ensures that the process is straightforward and intuitive, guiding you step 
by step with clear instructions and providing the QR code directly for easy setup.

1.4 Candidate Board
Overview
The Candidate Board is a Kanban-style feature that allows users to manage candidates visually 
by organizing them into different states based on their progress in the hiring process. This 
section is designed for simplicity and flexibility, enabling users to track and manage candidates 
efficiently while offering additional tools for sorting, customization, and data export.
Key Features of the Candidate Board
States (Columns):
oCandidates are organized into states (columns) representing stages in the 
recruitment pipeline (e.g., Selected, Contacted, First Choice).
oUsers can add new states to customize the board for their specific workflow.
Candidate Movement:
oCandidates can be moved across states to reflect their progression in the hiring 
process.
oDrag-and-drop functionality is available to rearrange candidates:
Across states: Move candidates between different stages (e.g., from 
"Contacted" to "Interview Scheduled").
Within a state: Reorganize candidates by priority or any user-defined 
criteria.
Sorting Options:
oCandidates within a state can be sorted alphabetically
Three-Dot Menu (State Options):
Each state has a three-dot menu with additional actions for managing that column:
oSelect All / Deselect All : Quickly select or deselect all candidates in the 
state.
oRename: Edit the state name for better customization.
oSet as Success State : Mark the state as the final stage (e.g., "Hired"). This 
designation is crucial for later analytics, such as:
Calculating time-to-hire.
Determining conversion rates.
oCreate Talentpool from State : Convert all candidates in the state into a 
reusable talent pool for future projects.
oAdd State to Talentpool : Include the state itself in a talent pool for broader 
usage.
oMove to Other Project : Relocate candidates from the current project to 
another project within the system.
oExport as .CSV : Download all candidate data from the state as a CSV file for 
external use.

Success State Setting:
oThe Set as Success State  option is critical for defining which state represents 
the final stage of the recruitment process (e.g., "Hired").
oThis setting is used later for generating recruitment statistics, including time-to-
hire and conversion rates.

E1.2.1 General
E1.2.1.1 Local Purchasing Power (LPP)  The Local Purchasing Power index is a 
fundamental metric that quantifies the relative buying capacity of a typical salary in a given 
location. This sophisticated measure takes into account average salaries and living costs to 
determine how much people can actually afford in different cities. It serves as a crucial indicator 
for understanding real-world living standards and economic conditions across different locations,  
going beyond simple currency conversions to reflect actual lifestyle possibilities.
E1.2.1.2 Income Comparison  The Income Comparison feature provides a nuanced 
analysis of salary equivalence between locations, accounting for differences in living costs, 
taxation, and economic conditions. This tool helps users understand what salary level would be 
needed in a different location to maintain their current standard of living, making it invaluable 
for career decisions and salary negotiations.
E1.2.1.2.1 Select Currency  The currency selection functionality enables users to view and 
compare financial data in their preferred currency. This feature ensures that users can understand  
costs in familiar terms while maintaining accurate relative values across different economic 
zones.
E1.2.2 Combined Metrics  The Combined Metrics section presents a comprehensive 
overview of key cost indicators, integrating various aspects of daily living expenses. This 
includes consumer prices with and without rent, grocery costs, and dining expenses. The system 
analyzes these factors collectively to provide a more complete understanding of cost differences 
between locations.
E1.2.3 Individual Comparison  The Individual Comparison feature offers detailed, 
category-specific cost analysis across different aspects of daily life:
Housing Costs A thorough examination of residential expenses, including rental costs for 
various apartment types, utility expenses, and property purchase prices. The analysis 
distinguishes between city center and peripheral locations, providing a comprehensive view of 
housing options and their associated costs.
