A4.1.1 Search Template
Allows searching for existing project templates by entering their name.
A4.1.2 Create New Project Template
Function to create a new project template.
A4.1.2.1 Name
Assign a name to the new template for unique identification.
A4.1.2.2 Add State
Add a recruitment process state to the template.
A4.1.2.3 Private/Shared
Define whether the template is only visible to the creator (Private) or accessible to the entire 
team (Shared).
A4.1.2.4 Save
Save the created project template for future use.
A4.2 Private Templates
Private templates are only visible to their creator. These templates can be sorted and managed 
as needed.
A4.2.1 Sort by Name (F)
Sort templates alphabetically by their name.
A4.2.2 States
Displays the states included in the template. - displays the number of states
A4.2.3 Team Members
Lists the team members associated with the template.
A4.2.4 Sort by Creation Date (F)
Sort templates chronologically by their creation date.
